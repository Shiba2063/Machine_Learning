# Machine Learning Workspace

This folder contains introductory Python examples for common data science
libraries:

- **NumPy** — arrays, operations, linear algebra, statistics, and data loading
- **Pandas** — Series, DataFrames, indexing, and CSV-based projects
- **Matplotlib** — plots and basic visualization examples

## Getting started

Create or activate a Python virtual environment, then install the libraries:

```bash
python -m venv .venv
source .venv/bin/activate
pip install numpy pandas matplotlib jupyter
```

Run an example from its directory, for example:

```bash
python NumPy/intro.py
python Pandas/intro.py
python Matplotlib/first_plot.py
```

The datasets and notebooks included in the subfolders are provided as learning
examples.
